# Customer Churn Prediction using Deep Learning

## 📌 Project Overview
This project focuses on predicting **Customer Churn** using **Deep Learning and Machine Learning techniques**. The model analyzes customer data and predicts whether a customer is likely to leave the company (churn) or remain with the company.

The project includes data preprocessing, handling missing values, feature engineering, data scaling, model training, and evaluation.

---

## 🚀 Features
- Data Cleaning and Preprocessing
- Handling Missing Values
- One-Hot Encoding of Categorical Features
- Feature Scaling using StandardScaler
- Train-Test Split
- Deep Learning Model using TensorFlow/Keras
- Model Evaluation and Prediction
- Confusion Matrix for Performance Analysis

## 📊 Workflow

1. Load the dataset.
2. Check for missing values.
3. Separate numerical and categorical columns.
4. Fill missing values:
   - Median for numerical columns
   - Most frequent value for categorical columns
5. Apply One-Hot Encoding.
6. Split features and target variable.
7. Scale the data.
8. Train the Deep Learning model.
9. Evaluate model performance.
10. Make predictions on test data.

---

## 📈 Output
The model predicts whether a customer will:

- **Stay with the company (0)**
- **Leave the company (1)**

This helps businesses improve customer retention strategies.
